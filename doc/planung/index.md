# 📋 Projektplanung — Team-Einteilung

[← Hauptseite](../index.md)

Jedes Team aus **2 Schüler:innen** entwickelt **ein kleines Spiel** zu einem **Schulfach**. So tragt ihr euch ein:

---

## ✏️ Eintragen ins Planungs-Sheet

👉 **[Hier klicken: Khevi-Game Planung (Google Sheet)](https://docs.google.com/spreadsheets/d/1s5qPQS__OhhOl5Gv_GTWRtIFwiI3yPyzwcC6LPX60lw/edit?usp=sharing){:target="_blank"}**

Im Sheet findet ihr eine Liste der Fächer. Tragt euer Team **(Vorname Nachname × 2)** und eure **Spiel-Idee** in der gewünschten Zeile ein.

---

## 📝 Regeln

- **Genau 2 Personen** pro Team
- **Ein Fach pro Team** — keine Doppelbelegung (wer zuerst einträgt, bekommt es)
- **Spiel-Idee** kurz beschreiben (1–2 Sätze reichen)
- **Bezug zum Fach** muss erkennbar sein (z.B. Mathe-Quiz, Geschichte-Memory, Englisch-Vokabeltrainer)

---

## 💡 Beispiele für Spiele

| Fach | Spiel-Idee |
|---|---|
| Mathematik | Rechen-Snake (richtige Lösung = Apfel) |
| Geschichte | Zeitstrahl-Sortier-Quiz |
| Englisch | Vokabel-Memory |
| Geografie | Länder-erraten-Karte |
| Biologie | Organe-Puzzle |
| Musik | Instrumenten-Hör-Quiz |

---

## 🚀 Wenn ihr eingetragen seid

1. **Team-Name und Nummer festlegen** (z.B. bu-anatomie = 2)
2. **Onboarding** durchgehen → [01-Installation](../onboarding/01-installation.md)
3. Eigenen Spiele-Ordner anlegen und Beschreibung einfügen `game2/readme.md`
4. Mit dem [Workflow](../workflow/index.md) starten
